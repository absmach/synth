# Synth logo

[synth-logo-monochrome.png](synth-logo-monochrome.png) is the primary Synth logo: a black geometric S and uppercase wordmark on white. Use it with generous clear space.

The asset is a raster PNG. It was generated with the built-in image generation tool; the [original prompt](synth-logo-monochrome-prompt.txt) is retained for reference. Its blank margins were cropped with ImageMagick, preserving the original artwork pixels and leaving 20 pixels of clear space on each side.
