# Synth logo

[synth-logo-monochrome.svg](synth-logo-monochrome.svg) is the primary Synth logo, used in the project README: a black geometric S and uppercase wordmark on white. It contains vector paths, requires no fonts or external assets, and scales without losing sharpness. The canvas includes 20 pixels of clear space on each side.

The SVG was traced from the [original PNG](synth-logo-monochrome.png) using Potrace 1.16 with a 50% grayscale threshold and 0.1 curve optimization tolerance. The paths use solid `#111111` on a white background. This preserves the selected design while smoothing its raster edges.

The PNG is retained as the source and raster fallback. It was generated with the built-in image generation tool; the [original prompt](synth-logo-monochrome-prompt.txt) is retained for reference. Its blank margins were cropped with ImageMagick, preserving the original artwork pixels.
