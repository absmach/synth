# Prompt

Design a complete, manufacturable six-layer PCB around a Lattice iCE40HX4K in a 121-ball, 0.8 mm pitch BGA, escaped under the pads with via-in-pad, that includes a power-only USB-C input with 5.1 kohm CC pull-downs and TVS diodes on CC1 and CC2, a 0.5 A resettable fuse, a 6.0 V standoff TVS diode, an AMS1117-3.3 regulator for the 3.3 V rail, a TLV70012 regulator for the 1.2 V core with a ferrite-filtered PLL supply, a decoupling capacitor on every supply ball, a 25 MHz oscillator on GBIN1, a W25Q128JVSIQ SPI boot flash with a 6-pin programming header, a 12-pin header carrying four FPGA I/O through 100 ohm series resistors, four status LEDs, test points on the rails and configuration signals, and two M2.5 mounting holes, using the Synth MCP server (`synth mcp`) to export the KiCad project and fab package.
