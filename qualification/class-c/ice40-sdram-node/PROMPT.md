# Prompt

Design a complete, manufacturable six-layer FPGA memory node PCB on the JLCPCB JLC06161H-3313 stackup with 50 ohm outer traces, powered from a 5 V USB-C sink receptacle with 5.1 k CC pull-downs, and include a 1.1 A resettable fuse, a PTVS6V0S1UR TVS diode, TPD1E10B06 ESD diodes on CC1 and CC2, a 1 ohm surge resistor, an AP7361C-33E 3.3 V LDO regulator, a TLV70012 1.2 V core regulator, a ferrite-bead-filtered PLL supply, an iCE40HX4K-TQ144 FPGA with a 25 MHz oscillator on a global buffer input, an IS42S16400J SDR SDRAM with 22 ohm series resistors and declared net classes, length-match groups and skew budgets, a W25Q128JVSIQ SPI boot flash, a 1x6 programming header, status LEDs, test points and two M2.5 mounting holes, using the Synth MCP server (`synth mcp`) to export the KiCad project and fab package.
