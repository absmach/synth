# Prompt

Design a complete, manufacturable six-layer iCE40 HDMI node PCB for JLCPCB advanced fabrication with via-in-pad and a declared stackup. It accepts 5 V through a 2-pin terminal and includes a 1.1 A resettable fuse, a TVS diode, a P-MOSFET reverse-polarity stage, an AP7361C 3.3 V LDO regulator and a TLV70012 1.2 V core regulator with ferrite-filtered PLL supplies. It also includes an iCE40HX4K-TQ144 FPGA with a 25 MHz oscillator and a W25Q128JVSIQ SPI boot flash. The FPGA drives an HDMI Type-A receptacle with four DVI-style TMDS pairs through 270 ohm series resistors. Each pair is declared at 100 ohm differential with a 25 mm skew budget. The board adds ESD arrays, a fused +5 V pin, level-shifted DDC, an HPD divider, four status LEDs, test points and two mounting holes. Produce it with the Synth MCP server (`synth mcp`), exporting the KiCad project and fab package.
