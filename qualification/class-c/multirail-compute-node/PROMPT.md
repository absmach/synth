# Prompt

Design a complete, manufacturable four-layer multi-rail compute node PCB that accepts a 5 V to 12 V DC input or USB-C VBUS, each protected by a resettable fuse and a TVS diode with Schottky reverse blocking, and includes an LMR33640 buck converter providing 3.6 V, an LP5907 3.3 V LDO, a TPS22918 load switch that sequences an AP2112K 1.8 V LDO and a TLV70012 1.2 V LDO, an STM32F103C8 microcontroller with an 8 MHz crystal, USB data, a W25Q128 SPI flash, an SWD header and a reset button, ESD protection on the USB lines, status LEDs, an expansion header, rail test points, fiducials, two M2.5 mounting holes and a keepout around the buck, using the Synth MCP server (`synth mcp`) to export the KiCad project and fab package.
