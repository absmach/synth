# Design summary

This is a summary of the delivered board, written after the board was finished. It is not the prompt the agent ran, and no agent prompt was kept in this repository. The nearest record of the brief is the cleaned version published in `absmach/synth-website` at `public/showcase/buck/prompt.md` (commit `22bc5390`); that file says it is not the exact text that ran.

Using synth mcp server design a four-layer 24 V to 3.3 V buck converter board for JLCPCB with the jlc-filled-via profile. Take 24 V nominal, up to 26.4 V, on a 2-pin JST XH input J1 through a 1.1 A resettable fuse F1, an SS36 Schottky reverse-polarity diode D1 and an SMBJ30A TVS D2, with 47 uF, 10 uF and 220 nF input capacitors. Use a TI LMR38010 regulator U1 at 800 kHz with a 6.8 uH inductor L1, three 22 uF output capacitors, a feedback divider tapped from the output side of L1 with a 56 pF feed-forward capacitor, and a UVLO divider on EN, to deliver 3.3 V at 1 A. Add a power-good pull-up, a power-good LED and a power LED, and a 4-pin JST XH output J2 with +3V3, GND, power-good and GND. Put J1 on the left edge and J2 on the right edge, mount it with two M2.5 holes in opposite corners, pour GND on all four layers, pin the placement, add six 0.3 mm GND vias in the exposed pad with via-in-pad declared, and write a negative twin that takes feedback from SW and must fail validation with E-SYNTH-POWER-011.
