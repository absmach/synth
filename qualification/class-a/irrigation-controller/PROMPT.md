# Prompt

Design a complete, manufacturable two-zone irrigation controller PCB that accepts a 12 V DC input through a JST XH connector, operating between 10.8 V and 12.6 V, and includes a 1.5 A resettable fuse, an SMAJ13A TVS diode, an LM74700-Q1 ideal-diode reverse-polarity stage driving a DMT6007LFG MOSFET, an MP2307 buck converter providing regulated 3.3 V, an STM32G030K8T6 microcontroller with a 32.768 kHz crystal, reset button and SWD header, two 12 V solenoid-valve outputs switched by low-side AO3400A MOSFETs with flyback diodes and shunt current sensing, two soil-probe inputs with AC excitation, a flow-meter pulse input, an I2C header with an APDS-9301 light sensor and 24LC256 EEPROM, field-connector ESD protection, status LEDs and test points, on a two-layer JLCPCB board, using the Synth MCP server (`synth mcp`) to export the KiCad project and fab package.
