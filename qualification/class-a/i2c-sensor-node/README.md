# I2C/SPI Sensor Node Board

USB-C programmed STM32G030 module with I2C/SPI sensor interface.

## Features
- STM32G030F6P6 MCU (TSSOP-20)
- BME680 environmental sensor on I2C
- 24LC256 EEPROM on I2C
- USB-C power and programming
- AMS1117-3.3 LDO regulator
- SWD debug header
- JST XH power input
