# Prompt

Design a complete, manufacturable two-layer I2C sensor node PCB powered only from a 5 V JST XH input, protected by a 0.5 A resettable polyfuse, a 1N5819 Schottky diode against reverse polarity and a PTVS6V0S1UR TVS diode, with an AMS1117-3.3 regulator providing the 3.3 V rail. It includes an STM32G030F6P6 microcontroller with a reset button and an SWD programming header, a BME680 sensor and a 24LC256 EEPROM on one I2C bus with 4.7 k pull-ups, a JST PH UART connector for an external USB-UART adapter, and a 12-pin GPIO header, with every external line behind a series resistor and a 3.3 V zener clamp, and no USB. Produce it with the Synth MCP server (`synth mcp`), exporting the KiCad project and fab package.
