# Protected Power Entry Board

Protected power entry board with reverse-polarity and over-current protection.

## Features
- Q1 reverse-polarity PFET
- D1 SMAJ15A TVS (over-voltage protection)
- MP2307 5V buck converter
- TPS22918 load switch
- AMS1117 3.3V LDO
