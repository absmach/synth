# Prompt

Design a complete, manufacturable protected power-entry PCB that accepts a 12 V input operating between 10.8 V and 13 V and includes reverse-polarity protection using a MOSFET, a resettable fuse, a TVS diode, a buck converter providing regulated 5 V, a soft-start load switch, and a 3.3 V LDO regulator, using a 1.5 A polyfuse, an SMAJ13A TVS on the fused input ahead of an AO3401A P-MOSFET, an MP2307 buck with a 44.2 k and 10 k divider, a TPS22918 switched 5 V output enabled by LOAD_EN, and an AMS1117-3.3, plus JST XH outputs, an 8-pin control header with clamped sense lines, status LEDs and four corner mounting holes on a two-layer board, produced with the Synth MCP server (`synth mcp`), which exports the KiCad project and fab package.
